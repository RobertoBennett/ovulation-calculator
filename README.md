# Ovulation Calculator Widget with AJAX

## Описание
Виджет калькулятора овуляции для WordPress с расчетом без перезагрузки страницы.

## Основные характеристики
- Расчет дня овуляции на основе последней менструации
- Учет длины цикла и возраста пользователя
- AJAX-обработка без перезагрузки страницы
- Адаптивный дизайн с приятной цветовой схемой
- Подробные пояснения к результатам расчета

## Установка
1. Загрузите файл `ovulation-calculator-widget.php` в папку `/wp-content/plugins/`
2. Активируйте плагин через меню 'Плагины' в WordPress
3. Используйте шорткод `[ovulation_calculator]` на любой странице или в виджете

## Использование
1. Введите дату начала последней менструации
2. Укажите среднюю длину цикла (21-35 дней)
3. Укажите ваш возраст (18-50 лет)
4. Нажмите кнопку "Рассчитать"

## Результаты расчета
Плагин отображает:
- День овуляции (ожидаемая дата)
- Начало окна фертильности
- Окончание периода фертильности
- Подробные пояснения для каждого параметра
